# MarketView En - 完整功能網站（本機版）

你是不是常常**漏掉最新、最重要的市場新聞**？**法人說明會**的時程與內容**沒跟上**？**財報公布**將近才發現、節奏老是落後一截？

這個專案把**新聞聲量、盤前、台美股與國際行情、法說／總經事件**等，盡量收成**同一個看盤頁**；介面是**可摺疊區塊**、可**分區更新**，幫你**省下反覆搜尋、開一堆分頁拼湊資訊的時間**。

其中首頁 **「新聞聲量 · 盤前」之上的「🤖 AI 速覽」**（後端：`news_analysis/ai_digest.py`）會**串接 LLM API**，把當下已彙整的**新聞聲量、台美股盤前脈絡與主要指標簡報**打成**一篇可快速閱讀的每日盤勢／市場摘要**，在純資料看板之外，多一層**統整後怎麼看**的輔助。

**請注意：專案內不包含、也不代收任何 LLM 金鑰。** 若要使用 AI 速覽，請你**自行到 Google AI Studio／OpenAI（或相容服務）申請 API key**，再依下方環境變數說明寫入專案根目錄的 **`.env`**（可複製 `.env.example`）；**切勿把含金鑰的檔案推上公開 GitHub**。

與作者日常使用的版本相同：**在本機跑滿資料抓取與運算**，不受雲端 IP 限制，**台股／國際報價、新聞與盤前等區塊較能完整發揮**。

- **本機完整版（本 repo）**：clone 後 `python app.py`，以終端機顯示的網址為準（預設多為 [`http://127.0.0.1:5001`](http://127.0.0.1:5001)，亦可透過環境變數 `PORT` 覆寫）。
- **雲端示意版（免安裝試用）**：[`https://trading-system-kkhs.onrender.com/`](https://trading-system-kkhs.onrender.com/) — 功能受雲端與資料源限制較多，僅供快速體驗介面。

行情資料以 **Yahoo Finance (yfinance)** 等為主，主要流程無需 Finnhub / Binance / Twelve Data API key。

### AI 速覽（LLM）環境變數（自行申請金鑰後填入）

擇一即可；建議寫入 **`.env`**：

- 優先：`GEMINI_API_KEY`（可選 `GEMINI_MODEL`，預設 `gemini-2.5-flash`）
- 若未使用 Gemini：`OPENAI_API_KEY`、`OPENAI_BASE_URL`（選填）、`OPENAI_MODEL`

## 首頁各區塊：做什麼、能幫你什麼

以下順序對應畫面上的折疊區塊標題。

### 🤖 AI 速覽

- **區塊做什麼**：串接 **LLM**（Gemini 或 OpenAI 相容 Chat API），把你當時已載入／快取中的**新聞聲量、盤前脈絡與主要指標快照**統整成**一篇可快速讀完的盤勢／市場重點**；可按「🔄 重算」再打一次結論。
- **能幫你什麼**：在資料很多時，先做**口述級的提要**，省了逐條新聞掃完的時間；方便開盤前、收盤後快速對焦「今天在吵什麼、市場大概在反映什麼」。

### 🇺🇸 美股市場

- **區塊做什麼**：主要指數與個股報價、財報行事曆更新。
- **能幫你什麼**：同一視窗掌握**美股標的與即將發布財報的標的**，對照接下來美股新聞與盤前區塊。

### 🇹🇼 台股市場

- **區塊做什麼**：台股報價、約 **60 天內**台股財報行事曆。
- **能幫你什麼**：看個股或大盤同時**預先做財報時程對照**，減少漏看重要發布。

### 國際 · ETF · 金屬 · 加密 · 比率

- **區塊做什麼**：國際主要指數；美股／台股 **ETF**（如 VOO、QQQ、0050）；**COMEX** 重金屬；加密 **24h**；數個**重要比率**（比率可進一步點開看 **Chart.js** 走勢）。
- **能幫你什麼**：用一頁對照**Risk-on／off、資產輪動、大宗商品與匯／債敏感度**的大概方向，適合組合配置與環境感的快速自查。

### 📰 新聞聲量（前24h） · 🌅 盤前資料

- **區塊做什麼**：前一日滾動的**新聞關鍵詞聲量**（可展開連結）；**台股／美股盤前**分開更新。
- **能幫你什麼**：抓出**市場集中度高的議題**，再對照各自盤前的報價與情緒，是 **AI 速覽很重要的輸入來源**，也適合你不想只看價線、要看「今天在談哪些主題」的時段。

### 📊 三大法人買賣超專區

- **區塊做什麼**：證交所 **BFI82U**（三大法人）**累計買賣超**視覺化；可**指定日期區間**並**上傳 CSV** 補歷史或修正。
- **能幫你什麼**：用**資金結構／籌碼面**對照你已看到的新聞與價量，並用自備檔維護自己的資料備份。

### 📊 Benchmark 績效試算

- **區塊做什麼**：自訂**起迄日**，查多個全球主要指數在同一期間的**起終點位與期間報酬**。
- **能幫你什麼**：快速回答「這段時間美股／亞洲／台灣等大盤**誰強誰弱、大概差幾％**」，利於複盤或寫紀錄。

### 📅 法人說明會 · 📅 總經

- **區塊做什麼**：**法說時程**（可上傳／下載 CSV 整理資料）；連到 **BLS** 發布行事曆等**總經議程**，事件可寫**筆記並儲存**。
- **能幫你什麼**：把**個股資訊面（法說）**與**總經數據面**並排在看盤同一天裡，減少在瀏覽器分頁與 Excel 之間往返。

## 「選股」分頁（`/selecting`）

- **做什麼**：台股為主的**條件範例**，例如連續毛利率、近月營收年增、均線排列（例如 `5MA > 20MA`）等；後端可多執行緒掃描較大批標的。
- **能幫你什麼**：從「看環境／看大盤」切到「**拉出符合條件的清單**」，再做人工精選與進一步研究。

後端尚有策略比對類 API（`strategy/`），可作延伸整合；頁面上的研究主流程仍以**看盤首頁 + 選股頁**為主。

## 專案結構（摘要）

```
marketview_pro/
├── app.py                 # Flask 主程式
├── config.py
├── market_data/           # 行情與資料擷取
├── timing/                # 擇時
├── strategy/              # 策略匹配
├── selecting/             # 選股篩選
├── news_analysis/         # 新聞／盤前、`ai_digest.py`（AI 速覽）
├── economic_data/         # 總經相關
├── templates/             # index.html、selecting.html
├── static/
└── requirements.txt
```

## 安裝與使用

### 1. 下載專案

```bash
git clone https://github.com/En0526/marketview_pro.git
cd marketview_pro
```

### 2. 安裝依賴

```bash
pip install -r requirements.txt
```

### 3. 運行應用

```bash
python app.py
```

### 4. 訪問網站

瀏覽器開啟：**http://localhost:5001**（看盤；若已改 `PORT` 請改連接埠）  
選股：**http://localhost:5001/selecting**
